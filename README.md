## Overview

InternTrack brings resume analysis and job discovery into one workflow. It extracts skills from resumes, surfaces job listings through the Adzuna API, and provides placement estimates using a Random Forest model.

## Key Features

- **Resume parsing:** Extract information and skills from uploaded resumes.
- **Job discovery:** Retrieve job listings through the Adzuna API.
- **Career guidance:** Use extracted skills to support personalized career exploration.
- **Placement estimates:** Apply a Random Forest model to estimate placement outcomes.
- **Live dashboard updates:** Use WebSockets to refresh dashboard information.
